## 免费版 TAPD 的 API 可用性（关键事实，已核实）
- 大大反馈「TAPD 是免费版，用不了 api 模式」——这是把「API 账号」和「个人令牌」混为一谈，实际结论是：**免费版可用，走个人令牌**。
- 官方口径（`open.tapd.cn` 使用必读原文）：「目前TAPD API是TAPD的商业化模块，TAPD企业版的公司管理员可以在公司管理>开放集成>API账号管理中申请试用90天」→ 挡的是 **API 账号（api_user/api_password，Basic Auth）**，免费版没有。
- 官方口径（`tapd.cn/help/1120003271001001197` 原文）：「免费企业：2000次api调用/天」，入口「公司管理—>开放集成—>个人令牌管理」，且「个人令牌不受项目级字段/工作流权限管控」→ **免费企业有个人令牌，2000 次/天**。
- 鉴权方式：个人令牌用 `Authorization: Bearer <token>`（官方 API 文档里与 Basic Auth 并列，示例 `curl -H 'Authorization: Bearer ACCESS_TOKEN'`）；个人 token 调接口不需要传 current_user。
- 实机探测（本机直连 api.tapd.cn 通，无需代理）：
  - 无凭据 → `HTTP 401 {"status":401,"info":"401 Unauthorized"}`
  - 带无效 Bearer → `HTTP 422 {"status":422,"info":"The access token provided is invalid"}`
  - 若是免费版封禁 API，应是 403「未开通」这类，而返回的是「令牌无效」→ 佐证个人令牌路径通。
- 待大大确认：TAPD 界面里「个人设置 → 个人访问令牌」在免费版是否可生成。若确实没有，降级方案是「Excel 导出 + 插件读本地文件」（免费版有 Excel 导出），Cookie 抓取不推荐（违反 ToS 且易失效）。

## 0.2.5：修「面板保存不了 / 测试连接没反应」（根因已坐实）
- 现象：桌面端装完后，填令牌 + 项目 ID 点保存，表单又弹回来、令牌框被清空；点测试连接无任何反应。`~/.dsh/tapd/` 始终不存在（说明 PUT 根本没到宿主）。
- 根因（读 `/Applications/DeepSeek Harness.app/Contents/Resources/app.asar` 里的宿主代码核实）：
  - 桌面端界面跑在自定义协议 `dsh-app://app` 上；`lib/main.js` 里 `protocol.registerSchemesAsPrivileged` 把 `dsh-app` 注册为 standard/secure/supportFetchAPI/corsEnabled，页面里非静态路径的请求由 `forwardWebRequest()` 带上 `hostCookie` 转发给宿主。
  - `@deepseek-ai/dsh-host-webserver` 就是裸 `node:http` + 前缀路由表，**没有任何 CORS 头**，也不认跨源 cookie。
  - 旧代码 `routeBase()` 优先用 `__DSH_TRANSPORT__.streamBaseUrl`（= `new URL(hostUrl).origin`，形如 `http://127.0.0.1:<端口>`）。从 `dsh-app://app` 打过去是跨源请求 → 浏览器拦掉（Failed to fetch），所以保存/探活全部失败。
- 修法：`routeBase()` 改成优先 `document.baseURI`（同源），file:// 才回退，`streamBaseUrl` 只作兜底。
  - 桌面端 → `dsh-app://app/tapd/...`（主进程转发 + cookie）；Web 端 → `http://宿主:端口/tapd/...`（本来就同源）。
- 顺手修掉两个体验坑：
  - 「测试连接」现在把表单里**未保存**的值作为 body 发到 `POST /tapd/__test`（`runTest` 新增 override 参数，只在本次探活用，不落盘）。
  - 保存失败时不再清空令牌输入框；`probe()` 补了 catch（原来探活失败是静默的）；`send()` 把「请求没发到宿主」和「宿主报错」分开提示。
- 测试：`test/client.smoke.mjs` 新增同源断言（在 `document.baseURI='dsh-app://app/index.html'` 下点保存，实际请求必须是 `dsh-app://app/tapd/__config`，且不许出现 127.0.0.1）；`test/routes.smoke.mjs` 新增「未保存也能探活」。三个冒烟测试全绿。
- 版本 0.2.5。以后同类插件（weknora-in-dsh 同款代码）也有这个坑，改法一致。
